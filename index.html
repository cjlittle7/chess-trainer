Game libraries (master games, your own games)

A library holds many real games as an opening tree, so the explorer can show how often each move was played and how often White, Black or neither won. Only the first moves of each game are kept.

Add games

Big downloads are slow on a phone and use its storage. Lichess lets a username download run at roughly 20-30 games per second. If chess.com can't be reached from the browser, use tools/download_games.py on a computer and import the PGN file it makes. Compressed files (.zip, .zst) must be unpacked first.
Backup & sync

Your collections are stored in this browser, on this device only. Export a backup file to keep a copy or to move your lines to another device.
